# Contributing

This project maintains reproducible numerical models and benchmark datasets for graded-plate vibration. Contributions involving verification, software improvements, and technical documentation are welcome.

Corrections to numerical results should identify governing assumptions, solver version, mesh, boundary conditions, input data, and a reproducible test. Changes to the analytical nonlinear formulation should describe their relation to the 2018–2020 equations and the associated verification procedure.

Repository code and original documentation are available under the MIT License.
